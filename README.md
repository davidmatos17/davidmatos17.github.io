# davidmatos17.github.io

Personal portfolio of David Matos, served by GitHub Pages at https://davidmatos17.github.io.

Plain static HTML/CSS/JS, no build step. To preview locally, open `index.html` or serve the folder:

```bash
python -m http.server
```

- `assets/` – stylesheet and script
- `images/` – photo and favicons
- `files/` – CV, cover letter and recommendation letter (PDF)
